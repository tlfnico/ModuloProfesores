# Directorio de Especificaciones Técnicas (`docs/specs/`)

Este directorio albergará las especificaciones técnicas detalladas y los documentos de diseño por tarea o funcionalidad (RFCs / Specs) que se elaboren en etapas posteriores del proyecto.

## Propósito

- Contener especificaciones funcionales y no funcionales por módulo antes de iniciar su codificación.
- Servir de insumo directo para la implementación incremental del MVP según el Roadmap.
- Mantener la trazabilidad de requisitos, contratos de endpoints, esquemas de datos y casos de prueba.

## Convención de nombres propuesta

- `SPEC-001-xxx.md`: Especificaciones de arquitectura base o infraestructura.
- `SPEC-002-xxx.md`: Especificaciones de contratos y modelos de datos.
- `SPEC-003-xxx.md`: Especificaciones funcionales de casos de uso (ej. Asistencia, Comisiones, Observaciones).
